Magic 8 Ball
Programmer: Zarek Johnson

A desktop-based Magic 8 Ball application built with Python and Tkinter. This interactive GUI app lets users type in any burning question and receive a randomized classic 8-ball fortune!

Features
Graphical User Interface (GUI): Clean, dark-themed interface built using Python's native Tkinter library.

Input Validation: Prompts the user with an error message if they try to submit a blank question.

Keyboard Shortcut: Press Enter on your keyboard to submit your question instantly without clicking the button.

Randomized Responses: Selects randomly from a classic collection of affirmative, non-committal, and negative 8-ball answers.

Getting Started
Prerequisites
You need Python 3.x installed on your system. tkinter comes pre-installed with standard Python installations on Windows and macOS.

Installation & Running
Clone or download this repository/script.

Save the code into a file named magic_8_ball.py.

Open your terminal or command prompt, navigate to the folder where the file is saved, and run:

Bash
python magic_8_ball.py
